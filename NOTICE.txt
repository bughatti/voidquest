VoidDB - the game data this addon ships
=======================================

VoidDB is built by the Void addons' own tools from:
  - Blizzard's World of Warcraft game data (the Game Data API and the WoW Forever client's own tables)
  - What Void addon players record and share in game (quest givers, mob spots, rares, trainers, ...)
  - Open data, under these licences:
